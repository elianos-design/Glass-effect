# GlassLens

A glass effect OFX plugin, inspired by the Mirage plugin built in Rust using Craftanything.

## Compatibility
- Windows 64-bit
- OFX hosts (DaVinci Resolve, etc.)

## Installation
1. Download `GlassLens.ofx.bundle.zip`
2. Extract it to:
   `C:\Program Files\Common Files\OFX\Plugins`
3. Restart your host application.

In DaVinci Resolve, find it under **Effects → OpenFX**.
